# ドキュメントメタ情報

このページは、AuspiQ のプロダクト docs そのものについての補助メモです。end-user / developer のどちらかに閉じない、docs 全体の構造や取り扱い方をここで案内します。

## ドキュメントの見方

- `docs/README.md` は audience-first の入口です
- `docs/end-user/` は AuspiQ を使う人向けです
- `docs/developer/` は AuspiQ を変更、保守、拡張する人向けです
- `docs/appendix/` は changelog や meta 情報の置き場です

## 文書種別

- tutorial: 初めての人を成功させる学習パス
- how-to: 既に基本を知っている人の task guide
- reference: authoritative source
- explanation: why と mental model

## 現在の扱い

- docs 更新ルールは [../developer/policies/documentation-policy.md](../developer/policies/documentation-policy.md) にあります
- 実装とデータのズレは [known-gaps.md](./known-gaps.md) と developer reference の両方で追います
