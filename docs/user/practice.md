# 練習機能ガイド

auspiqの練習機能を使って、解析済み問題ファイルで実際の早押しクイズの練習を行う方法を説明します。

## 練習機能の概要

練習機能では、予測機能で解析済みの問題を使って：

- **リアルタイム文字表示**: 実際の早押しクイズのように文字が順次表示されます
- **対戦システム**: プレイヤーvsシステム（AI）の対戦形式で練習できます
- **解答権システム**: 早押しで解答権を獲得し、実際に解答を入力できます
- **自動停止**: AIが高い確信度を持った位置で自動的に一時停止します
- **スコア管理**: 正解・不正解を記録し、リアルタイムでスコアを表示します
- **インタラクティブ操作**: キーボード操作で練習をコントロールできます
- **複数問題対応**: 連続して複数の問題を練習できます

## 基本的な使用方法

### 練習セッションの開始

```bash
# 解析済みファイルを使って練習開始
auspiq practice --file results.json

# 自動停止の閾値を設定（デフォルト: 80%）
auspiq practice --file results.json --threshold 85

# 文字表示速度を設定（デフォルト: 0.1秒/文字）
auspiq practice --file results.json --speed 0.05

# 開始する問題番号を指定
auspiq practice --file results.json --start-from 5

# 練習する問題数を制限
auspiq practice --file results.json --limit 10
```

### 短縮オプション

```bash
# よく使用する短縮形
auspiq practice -f results.json -t 90 -s 0.08 -n 0 -l 5
```

## 練習中のキーボード操作

練習セッション中は以下のキーで操作できます：

### 問題文表示中の基本操作

| キー | 機能 | 説明 |
|------|------|------|
| **Enter** | 解答権獲得 | プレイヤーが解答権を獲得（早押し） |
| **a** | 解答表示 | 正解を表示して次の問題へ |
| **n** | 次の問題 | 現在の問題をスキップして次へ |
| **q** | 練習終了 | 練習セッションを終了 |
| **Ctrl+C** | 強制終了 | 緊急時の強制終了 |

### 解答権獲得後の操作

| キー | 機能 | 説明 |
|------|------|------|
| **Enter** | 解答入力 | 解答を入力するモードに移行 |
| **c** | 問題文継続 | 解答権を放棄して問題文表示を継続 |

### システム自動停止時の操作

AIが高い確信度を持った時、システムが解答権を獲得します：

| キー | 機能 | 説明 |
|------|------|------|
| **Enter** | システム解答 | システムが解答を行う |
| **c** | 問題文継続 | システムの解答権を無視して問題文継続 |

## 対応ファイル形式

練習機能では予測機能で生成された解析結果ファイルを使用します：

```json
{
  "questions": [
    {
      "question": {
        "original_text": "問題文...",
        "correct_answer": "正解"
      },
      "analysis_points": [
        {
          "position": 20,
          "text_so_far": "問題文の途中まで/",
          "candidates": [...],
          "total_probability": 85
        }
      ]
    }
  ]
}
```

**対応ファイル形式:**
- 解析結果ファイル（JSON形式）のみサポート

## 詳細設定

### 自動停止閾値の調整

```bash
# 慎重派（高い閾値）- より確実になるまで待つ
auspiq practice -f results.json --threshold 90

# 積極派（低い閾値）- 早めに押すチャンスをつかむ
auspiq practice -f results.json --threshold 70

# カスタム閾値
auspiq practice -f results.json --threshold 85
```

**推奨設定：**

- 初心者：85-90%（確実性重視）
- 中級者：80-85%（バランス）
- 上級者：70-80%（積極性重視）

### 表示速度の調整

```bash
# ゆっくり（初心者向け）
auspiq practice -f results.json --speed 0.15

# 標準速度
auspiq practice -f results.json --speed 0.1

# 高速（上級者向け）
auspiq practice -f results.json --speed 0.05

# 超高速（実戦レベル）
auspiq practice -f results.json --speed 0.03
```

### 問題の選択

```bash
# 特定の問題から開始
auspiq practice -f results.json --start-from 10

# 問題数を制限
auspiq practice -f results.json --limit 5

# 特定範囲の練習
auspiq practice -f results.json --start-from 5 --limit 3
```

- **○**: 正解数

## トラブルシューティング

### ファイルが読み込めない

```bash
# ファイル形式を確認
file results.json

# ファイル内容を確認
head -20 results.json
```

### キー操作が効かない

- ターミナルがアクティブになっているか確認
- 文字入力モードではなく、キー操作待ちモードか確認
- Ctrl+Cで一度終了して再起動

### 自動停止しない

```bash
# 閾値を下げて試す
auspiq practice -f results.json --threshold 60

# 解析ポイントがあるかファイル内容を確認
```

## 練習セッションの記録

練習中の操作や結果は自動的にログに記録されます：

```
logs/auspiq_practice_20240913_143022.log
```

ログには以下の情報が含まれます：

- 練習開始時刻
- 使用した設定値
- 各問題での自動停止タイミング
- ユーザーの操作履歴

## 練習のバリエーション

### シナリオ1: 初心者向け基礎練習

```bash
# システムから学ぶ安全重視モード
auspiq practice -f basic_questions.json -t 90 -s 0.15 -l 5
```

**目標**: システムの早押しタイミングを観察して学習
- 高い確信度でのみシステムが自動停止
- プレイヤーは安全なタイミングを身につける

### シナリオ2: バランス重視の対戦練習

```bash
# プレイヤーvsシステムの競り合い
auspiq practice -f standard_questions.json -t 80 -s 0.1
```

**目標**: プレイヤーとシステムが同程度の強さで対戦
- お互いにチャンスがある設定
- 判断力と反応速度の両方を鍛える

### シナリオ3: アグレッシブ練習

```bash
# プレイヤー有利設定で攻撃的な早押し練習
auspiq practice -f challenge_questions.json -t 70 -s 0.05
```

**目標**: リスクを取った攻撃的な早押しの習得
- システムより先に答えるチャンスが多い
- 不正解のリスクも含めて練習

### シナリオ4: 実戦シミュレーション

```bash
# 実際のコンテスト環境を再現
auspiq practice -f contest_questions.json -t 75 -s 0.03
```

**目標**: 実際の大会に近い環境での練習
- 高速表示で瞬間判断力を鍛える
- プレッシャー下での解答能力向上

### シナリオ5: 弱点克服練習

```bash
# 間違えた問題や苦手分野に特化
auspiq practice -f weak_areas.json -t 85 -s 0.1 -l 10
```

**目標**: 特定の弱点を集中的に改善
- 少し高めの閾値で確実性を重視
- 苦手分野での正解率向上
