# 開発の始め方

このセクションは、新しく AuspiQ の開発に入る人が、最短で環境を立ち上げ、基本の流れを掴むための入口です。最初は内部仕様の細部よりも、動かせること、出力の置き場所が分かること、コード配置で迷子にならないことを優先します。

ここで目指す到達点は次の通りです。

- CLI がローカルで起動する
- 解析、生成、練習の基本フローを 1 度ずつ触る
- どの実行でどこに何が保存されるか分かる
- コードベースの大まかな地図を持つ
