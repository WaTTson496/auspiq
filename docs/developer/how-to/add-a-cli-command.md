# CLI コマンドを追加する

このページは、新しいトップレベルコマンドやサブコマンドを追加するときの作業手順です。

## 触る場所

- `src/auspiq/cli.py`
- `src/auspiq/commands/`
- 必要なら `src/auspiq/models.py`
- 必要なら `docs/end-user/` と `docs/developer/`

## 手順

1. 新しいコマンドの責務を決めます。
2. `commands/` 配下に実装を置きます。
3. `cli.py` で登録します。
4. グローバルオプションや `ctx.obj` の伝播が必要か確認します。
5. 入出力の保存先と JSON 契約を決めます。
6. docs を更新します。

## 確認ポイント

- CLI 層だけの変更で済むか
- core ロジックを分離すべきか
- end-user 向け手順と reference の両方に影響するか
- 既存のログ、results、jobs の保存規約に沿っているか

特に AuspiQ では、CLI 追加と同時に「何を保存するか」「どの JSON を後続で読めるか」が問題になります。画面表示ができるだけでは不十分で、既存フローとの接続も確認する必要があります。
