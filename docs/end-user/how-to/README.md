# ハウツー

このセクションは、既に AuspiQ の基本を理解している人が、作業を完了するために使うガイドです。ここではコマンド名ではなく、利用者が終えたい作業ごとにまとめます。

各ページでは次の観点を揃えます。

- どんな前提で使うか
- 何を実行するか
- どこまでできれば成功か
- 失敗したらどこを見るか

how-to は reference の代わりではありません。手元の作業を終えるための導線なので、仕様の網羅はしません。その代わり、作業中に迷いやすい判断を扱います。

- `predict single` と `predict full` のどちらを選ぶか
- `generate` の制約をどの順に足すか
- 解析結果で練習するか、生成結果で練習するか
- 設定ファイルを変えるか、CLI オプションで一時的に済ませるか
