# 利用者向けドキュメント

AuspiQ を使って問題を解析し、問題を生成し、その結果を使って早押し練習をしたい人のためのドキュメントです。

AuspiQ の中心機能は次の 3 つです。

- `predict`: 問題文の途中または全文を解析する
- `generate`: 新しい問題を生成する
- `practice`: 解析結果や生成結果を使って練習する

この 3 つは独立ではありません。`predict` や `generate` が出力する JSON は、そのまま `practice` に入力できます。

AuspiQ は、設定ファイル、ログ、結果 JSON、ジョブ台帳をローカルに残す CLI です。そのため、「どのコマンドを打つか」だけでなく、「何がどこへ保存されるか」を把握して使うと迷いにくくなります。

このセクションでは、end-user が抱きやすい 4 種類の必要を分けて扱います。

- 初めて使うので、まず動かして成功体験を得たい
- すでに基本は分かっていて、今やりたい作業を終えたい
- 設定キーや JSON 仕様や保存先を正確に確認したい
- 解析・生成・練習をどう使い分けるべきか理解したい

また、AuspiQ の各ワークフローは次のように役割が違います。

- `predict single`: 問題文の断片に対して、いま何が有力かを見る
- `predict full`: 問題全体を通して、どの位置で押せそうかを見る
- `predict batch`: 複数問題をまとめて同じ形で処理する
- `generate`: 条件つきで新しい問題を作り、選択情報や品質情報も残す
- `practice`: 解析結果または生成結果を使って練習する

以降のページでは、これらを単なるコマンドの列ではなく、作業全体の流れとして扱います。

## いま何をしたいですか

### 初めて使う

最初の成功体験を得たいなら tutorials から入ってください。

- [tutorials/README.md](./tutorials/README.md)

### 作業を完了したい

既に基本を知っていて、目的の作業を終えたいなら how-to を使ってください。

- [how-to/README.md](./how-to/README.md)

### 仕様を確認したい

設定キー、JSON 形式、保存物、各コマンドの正確な挙動を確認したいなら reference を使ってください。

- [reference/README.md](./reference/README.md)

### 背景を理解したい

解析・生成・練習をどう使い分けるか、なぜそのような設計になっているかを知りたいなら explanation を使ってください。

- [explanation/README.md](./explanation/README.md)
