# チュートリアル

このセクションは、AuspiQ を初めて使う人が安全に成功体験を得るためのレッスンです。ここではオプションの網羅や高度な設定は後回しにし、1本ごとに1つの到達点だけを扱います。

AuspiQ の end-user 体験は、次の 3 つの主題で捉えると分かりやすくなります。

- 解析を体験する
- 生成を体験する
- 保存物を練習へつなぐ

tutorial では、how-to のように分岐や比較を大量に入れません。代わりに、次の点を都度回収します。

- いま何を学んでいるか
- 何が成功状態か
- 画面や保存物のどこを見ればよいか
- 今はまだ扱わないものは何か

最短の読み順は、`first-analysis`、`first-generation`、`from-results-to-practice` です。これで AuspiQ の基本ワークフローが一通りつながります。
