# リファレンス

このセクションは、AuspiQ の end-user 向け仕様を正確に確認するための参照資料です。ここでは手順ではなく、何を受け付け、何を返し、どこに保存するかを記述します。

AuspiQ はローカルファイルを多く残す CLI なので、設定と保存物の仕様も独立した参照対象として扱います。

reference では、「どちらを使うべきか」「どう進めるべきか」は最小限しか扱いません。代わりに、入力制約、既定値、保存先、JSON 構造、実装上の注意点を曖昧さなくまとめます。
