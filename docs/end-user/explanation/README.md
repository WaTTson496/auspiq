# 解説

このセクションは、AuspiQ をどう理解し、どう使い分けるかを説明する読み物です。

ここでは手順やオプション一覧ではなく、「なぜそうなっているか」「どう考えると判断しやすいか」を扱います。

AuspiQ は、解析、生成、練習という別々のコマンドを持っていますが、利用者の立場では「何をしたいか」に応じてそれらを組み合わせることになります。explanation の役割は、その組み合わせ方を支える mental model を与えることです。

具体的には次のような問いに答えます。

- 解析にはなぜ複数モードがあるのか
- 生成になぜ設定項目が多いのか
- 練習は入力元によって何が変わるのか
- AuspiQ 全体をどういうワークフローとして捉えるとよいのか
