競技クイズの多くの問題文は、解答に対応する名詞語彙を核とする名詞句（NP）を中心に組み立てられます。NP にはしばしば1つ以上の連体修飾句が前置され、そのうえで次のいずれかの述部型で問われます。

SC型（コピュラ型）：
「N は ＋ WH ＋ でしょう？」のように、コピュラ「〜である」を前提に NP を主題化し、WH で該当する名詞を問う。
例：静岡県と山梨県の県境に位置する、標高3776mと日本で最も高い山は何でしょう？

OV型（呼称・命名型）：
「N を／N のことを／（VP＋形式名詞〔もの・こと・さま〕）を ＋ 何と ＋ いうでしょう？」のように、命名・呼称の動詞句の直接目的語として NP を置き、その呼称（名称）を問う。
例：「電気回路に流れる電流の大きさは、電圧に比例し、電気抵抗に反比例する」という物理学の法則を、提唱したドイツの物理学者の名から何というでしょう？

また、競技クイズの問題文は他に以下のような特徴を持ちます：
- おおよそ60文字〜100文字くらいの文字数から構成される
- 問題文は解答が一意に限定されるように作られる
- 問題文中に複数の情報が提示される場合、知名度の低い情報が前置され、知名度の高い情報が後置される
- 出題される題材の難易度は、解答者が答えられるか答えられないかの瀬戸際になるようなレベルから選ばれる

これを念頭に置いて、早押しクイズの問題文の推測を行ってください。

問題文をボタンが押された箇所（"／"で示す）まで表示するので、その先の問題文の候補と解答として考えられるものを、最大{max_candidates}つまで挙げてください。候補の問題文は続きの部分だけでなく全文を示してください。

それぞれの候補に対して、どのくらいの蓋然性があるかを0〜100%の数字で示してください。蓋然性の値が1%未満の時は<1%と書いてください。蓋然性は{max_candidates}つの候補だけでなく、挙げられなかったものも含めた全ての可能性の中で全体が100%になるようにしてください。挙げた{max_candidates}つの候補の蓋然性の合計値も示してください。押しポイントが早い場合は蓋然性の合計値は低い値になるはずです。

レスポンスは以下のJSON形式で返してください：

```json
{{
  "candidates": [
    {{
      "full_text": "完全な問題文",
      "answer": "解答",
      "probability": 蓋然性の数値（整数、1-100）
    }}
  ],
  "total_probability": 全候補の合計蓋然性（整数、1-100），
  "text_so_far": "入力された問題文の途中まで"
}}
```

ボタンが押されたところまでの早押しの問題文は以下の通りです：
{text_so_far}
